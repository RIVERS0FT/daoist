# 外卖修仙 v0.13：多选项外卖事件

所有有目的地的行动现在统一按地图距离计入通勤：总耗时 = 从当前保存位置到目的地的通勤 + 行动本身耗时。吃饭、休息、换电、车辆维护、修炼、人物见面、自由奇遇和系统兑换都会在实际执行时前往对应地点并更新“你在这里”；只打开面板、点击地标、查看任务、拖动/缩放地图仍完全免费。

配送路程改为“当前位置 → 商家 → 顾客”的地图距离，直接决定配送时间、电量/耐久需求、精力消耗与距离奖励，不再依赖随机公里数。普通通勤在车不可用时自动按步行速度计算，并且不消耗配送电量/耐久，避免没电时无法前往换电或维修。

成功配送现在可能进入多选项外卖事件。新增独立事件池包含商家卡单、楼宇故障、地址错误、售后争议、顾客额外请求、同行互助、暴雨配送、平台申诉和灵异异常等；每个新增事件至少 3 个选择，不同选择会影响时间、精力、金钱、信誉、关系或异常线索。配送现金、外卖币和到达位置仍先按正常规则结算，不会因事件重复发奖。

外卖系统仍是远程系统界面：兑换、任务奖励和成就奖励均为 0 分钟、无通勤、位置不变。成功配送仍获得外卖币；商城继续兑换青息草、素符纸、清心茶、归元散和护脉符。

系统页新增原创系统剧情、系统任务与隐藏成就。剧情会随第一单、灵气/境界、NPC 相识、异常记录和筑基进度逐章解锁；任务与成就只从已有世界状态判定，奖励固定且可验证，不直接送境界、不强制关系路线、不替玩家完成突破。旧存档继续兼容。

地图支持光标锚点缩放、单指平移、双指捏合与键盘平移/缩放；常驻界面只保留同排的放大、缩小、定位玩家三个按钮，不再显示旗帜定位终点。手动浏览暂停跟随，“定位玩家”恢复跟随。城市标题精简为“青岚市”，不再显示视角菜单或地点按钮。

修炼面板分为修行、功法、破境、药符；执行修炼前会把前往天台、山脚或旧书店的通勤计入总耗时。系统界面不属于地图行动，因此不受通勤规则影响。四门主修功法各有熟练度，法力与突破灵气分开；突破支持准备预览、稳妥/强行方案、可选护脉符与失败经验。炼气九层可进行三段内景试炼，完成后开放筑基初期。详细可验证成本见 `docs/CULTIVATION.md`。没有加入实时战斗、主动移动、宗门经营或现实时间挂机。

v1–v4 旧档自动升级为 v5；首次升级独立槽时原件保存在 `backup:pre-v5:<id>`，原 legacy autosave 仍保留。无需清档，不能在旧客户端继续写入 v5。AI relay 的 realmLevel 白名单已扩为 10；自行部署的旧 relay 需同步升级，否则筑基请求会明确回退为人工剧情。CI 使用模拟模型，无付费服务调用。

## 历史更新：v0.6 地图

城市画布扩大为 2400×1600；配送扩充为 24 个取餐点、40 个送达点。v0.9 起，无订单时地图显示本地确定的配送任务点；预览免费，点击“配送”后直接按实际配送时间完成，不再经过接单中间状态。地图保留生活/人物/修行等功能地标，并用“你在这里”显示玩家位置。

配送成功（骑行或推车）后角色停留在该订单目的地，位置随每个存档自动保存；刷新或切回存档可继续。任务预览、旧订单取消、骑行受阻或浏览地图不会移动玩家；成功配送直接更新位置。右上角只保留定位玩家。地图线段为示意，配送成本仍按本地引擎结算。旧存档不清档，无位置记录时从驿站补齐。

## 历史更新：v0.5 车辆与存档

开始页支持多个独立存档，经典 / AI 生成式剧情只在新建时选择，局内不可更改。每次行动自动保存，无需手动保存；可返回开始页继续其他仙途。旧 v1/v2/v3 单槽自动兼容升级并保留原件备份，不清空进度。

电动车没电、损坏或不足以完成全单时禁止骑行。跑单面板新增速度、电池容量、耐用性、节能四项升级及换电 / 维修；推车是明确的高耗时体力补救选项。存档仅保存在本机当前浏览器，清理网站数据会丢失本机进度。

## Daoist-Delivery / 外卖修仙

白天送外卖，晚上修仙。围绕时间取舍、NPC 关系与多结局的单机 Web RPG。

## 两种游玩方式

**经典剧情（默认）**：人工随机事件、NPC 分支与全部既有结局，不发送 AI 请求。正常跑单、修炼、生活、联系熟人，或点击“探索经典奇遇”。

**AI 生成剧情**：保留上述所有玩法；选择自由奇遇方向、可选熟人和虚构行动意图，由模型生成新场景及 2–4 个选择。本地规则显示并结算时间、资源和关系影响。最近的奇遇形成短期记忆，支持继续生成。

两个模式只在新建存档时选择，每个存档独立保存模式和进度，局内不可切换。每次探索先花 15 分钟和 2 精力，选择另计时间；失败回退不重复收费。已有 AI 场景存入本机，刷新不重抽，也可以断网后在当前模式下完成该段。AI 不直接修改主线旗标、人物路线、境界或结局。

## 开始玩

线上：https://rivers0ft.github.io/Daoist-Delivery/

开始页点击“新建存档”，选择经典剧情或 AI 生成式剧情；已有存档从列表继续。局内左下角“奇遇”与“更多 → 设置”只显示本存档的固定模式。AI 模式需要在“AI 服务设置”保存 relay 地址、授权及可选访问口令；没有服务或生成失败会明确回退为人工剧情，不伪装成 AI 已连接。接入步骤见 [server/README.md](server/README.md)。仓库提供可运行 relay，GitHub Pages 本身不运行模型服务。

不要在前端填写模型供应商 API Key。模型密钥只在服务端；relay 访问口令仅存在当前页面内存，刷新后重新输入。真实模型调用可能收费，未配置服务时经典玩法不受影响。

## 地图主界面

从开始页创建或继续存档后进入青岚市地图。顶部查看时间、天气与资源，左下角使用地图 / 跑单 / 修炼 / 关系 / 奇遇 / 更多导航；生活、状态、外卖系统、结局、帮助与设置在“更多”中。常驻功能地标直接在地图上点击进入，不再提供地点列表按钮。地图可拖动、缩放和定位，浏览不消耗时间。

无在途订单时，地图上的“单”任务点就是唯一新任务入口，不再额外显示“地图接单 / 选择地图上的配送任务”卡片。点击任务点免费预览，点击“配送”直接推进真实配送耗时并完成任务，不再先花 2 分钟接单。底部导航本体透明，地图画布真实延伸到导航按钮后方；按钮间的透明空白仍可操作地图。右下日志始终以多条纵向列表展示；待处理故事和旧存档当前配送保留必要的恢复入口。

地图为游戏内虚构区域，路线线条仍是示意；本地几何距离用于游戏内通勤结算。地图浏览本身不影响存档进度、人物路线或游戏时间。详见 `docs/MAP_INTERFACE.md`。
