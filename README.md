# Daoist-Delivery / 外卖修仙

白天送外卖，晚上修仙。一个以“时间永远不够用”为核心压力的单机 Web RPG。

## 当前可玩内容

- 行动驱动的连续时间与昼夜阶段
- 晴 / 多云 / 雨 / 雷暴天气
- 随机配送订单、高峰收益、车辆电量
- 金钱、精力、健康、压力、信誉、房租
- 夜间修炼、灵气、悟性、炼气一至九层突破
- 30+ 数据驱动随机事件与连续剧情
- IndexedDB 自动存档
- 响应式桌面 / 手机界面
- GitHub Pages 自动部署

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

设计规则见 `AGENTS.md` 与 `docs/`。
