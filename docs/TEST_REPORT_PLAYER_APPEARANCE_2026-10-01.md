# 玩家形象选择专项验证

日期：2026-10-01。源码：`public/`，应用 1.22.0，存档 schema v25。验证为本机隔离存档、Chromium 149.0.7827.55，无公网发布。

## 实现范围

- 新建旅程仅允许两款成年男性形象：清朗骑手 `male-rider`、沉稳骑手 `male-rider-steady`，默认清朗；原生单选卡片可预览。
- 所选形象显示在顶栏头像和角色面板，普通实时更新不重建头像图片；不增加局内切换入口，不影响数值、随机、时间和 NPC 剧情。
- 顶层 `appearanceId` 随自动保存、备份和导入导出保留；当前 v25 缺字段采用默认，女性/未知/外来路径等显式值拒绝。旧 schema 与旧存储键策略保持。
- 两张独立 RGB PNG 均为 1086×1448。素材和内置 `image_gen` 最终提示词见 `player-appearance-prompts.json`；女性选项及本次女性素材已移除。
