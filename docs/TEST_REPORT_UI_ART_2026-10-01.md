# 透明 UI 美术接入验证

日期：2026-10-01。应用 1.22.0，存档 v25；仅本机绘制、接入与专项验证，未提交、推送或部署。

## 结果与实现

- 使用内置 imagegen 分别绘制三张青玉暖金透明 PNG：面板四角、莲花标题纹饰、云纹分隔装饰。原稿保存在 `public/art/ui/`，清单见 [UI_ASSETS.md](UI_ASSETS.md)，完整最终提示词见 [ui-prompts.json](ui-prompts.json)。未裁切、缩小、压缩或替换已有美术。
- 普通面板采用九宫格固定角纹，标题下方和分组标题下方单独留白展示等比纹饰。真实文字、关闭按钮和正文滚动在装饰上层；伪元素不响应指针、不增加动画或游戏状态。解锁回执沿用独立视觉。
- 保留上一轮导航文字叠放与 0.6 px 细描边。真实 8787 四视口逐一点击十入口重合文字区域，40 次均进入原面板；原按钮范围、开放规则与暂停 JSON 保持，详见圆形导航报告追加章节。
- 服务器只新增三个固定 PNG 白名单路径，未知路径和私有文件仍拒绝；长驻 8787 服务已按原启动参数重启并实际验证，当前进程 PID 17000。

## 导出超时与验证边界

此前文字叠放后的两次专项在 trace 导出阶段超时，保留失败，不补记为通过。隔离诊断发现约 69.8 MB trace 分块导出需 15.437 秒，接近原 15 秒截止。只将采样停止后的导出等待改为 60 秒，保留超时异常，未改变场景时长、采样、预算或整帧口径。本报告四场景为修改等待后的正式独立复测。
