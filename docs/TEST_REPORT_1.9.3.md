# 1.9.3 已完成委托置底测试记录

日期：2026-09-20。基线：1.9.2 / 存档 v16；本次：1.9.3 / 存档仍为 v16。

## 变更范围

系统「委托」页将尚未领取的任务保留在上方，将已经领取并标记完成的每日／篇章任务统一放到列表最下方。组内保持原顺序，不改变任务可见性、完成条件、领取顺序、奖励、功能解锁、日志、时间推进或存档字段。

## 回归覆盖

浏览器渐进玩法流程在领取 q1 后重新打开委托页，检查每日任务与下一篇章仍位于上方，已领取 q1 的卡片实际纵向位置位于所有未完成卡片之后。每日卡片领取后复用同一 `complete` 状态，因此与篇章完成卡片遵循同一置底规则。

现有规则测试继续负责验证 `G.visibleQuests`、`G.questReady`、领取先后与奖励原子性；本次不改规则引擎和存档迁移，不新增 Node 规则分支。

## 验收命令

合并前标准 PR CI 必须通过：

- `npm run check`
- `npm test`
- `npm run build`
- `python tests/browser-smoke.py`

合并后还必须单独确认 `Deploy GitHub Pages` 工作流成功。最终 CI / Pages 结果以对应 GitHub Actions 运行记录为准。
