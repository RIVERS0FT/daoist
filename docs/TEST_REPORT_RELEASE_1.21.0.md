- `npm run build`：成功，158 个本地静态资源加校验清单。
- 浏览器整套功能范围：**257 项通过**。前 238 项完成后，炼药用例中“首章存档发现全市地址”的旧夹具被新区域校验拒绝；修正为原城区已发现地点，再从该独立用例开始执行余下 19 项并全部通过。前段未重复执行，应用源码在两段之间没有修改。

完整浏览器使用受控游戏时钟和模拟 AI；另有真实 RAF、后台心跳及托管 CSP 沙箱检查。没有调用真实 AI 服务，也未使用或修改用户存档。分段执行日志在忽略目录 `artifacts/release-browser-smoke-final.log` 和 `artifacts/release-browser-tail.log`。

## 构建版帧预算

`browser-performance.py --root dist --output artifacts/performance-release`：桌面 1440×1000 与手机 375×812，各八个场景，**16 / 16 通过**。包括静止自动保存、拖动、滚轮缩放、真实移动、面板、全市总览平移、分区加载和外围细节平移。

跨场景最差 P95 为 19.272 ms，P99 为 23.884 ms，最大帧长 98.484 ms，最高超预算比例 9.594%。保留原门槛 P95 ≤ 33.5 ms、最大 ≤ 150 ms、超预算比例 ≤ 10%。200 ms 阻塞自检观测 202.891 ms，正确检出。

逐帧列出全部 20 个加载模块的 V8 采样自耗时，并记录浏览器布局、绘制、合成、栅格和 GPU 服务线程开销。区域场景使用已开放全图的隔离状态。报告与 trace 在 `artifacts/performance-release/`；采样零值不是绝对零耗时，线程时间不能相加当帧长，headless RAF 测量不代表用户设备或物理屏幕呈现时间。
