# 左上玩家立绘与状态条专项验证

日期：2026-10-01。源码：`public/`，应用 1.22.0，存档 schema v25。本机隔离存档及 Chromium 浏览器验证，未发布。

## 实现范围

- 左上显示当前存档选择的男性完整半身立绘，保持 3:4 比例，使用 `contain`；点击立绘或姓名可查看角色属性。
- 姓名、境界及纵向气血、体力、灵力、电量条置于立绘右侧。灵力沿用修行开放门槛；数值、上限、比例和无障碍属性均从引擎状态派生。
- 顶栏占据实际布局高度，地图由现有 ResizeObserver 响应可用空间；普通实时更新保留立绘、状态条和倍率节点。进度百分比规范到四位小数，避免 CSS 序列化引起同值重复赋值。
- 手机保留可见资源条和 44 px 主要控制；短屏压缩章节说明并改为两列地图控制，保留章节标题、配送进度、区域和位置。320 px 属性面板统计列允许收缩，防止长数值裁切。
- 沿用两款男性形象及存档约束，不增加女性选项、局内切换或外观数值收益。
