# 界面纹饰素材

当前三张 v2 透明原稿已接入普通面板，参考《黑神话：悟空》的金石氛围，独立绘制克制的古铜云雷纹饰，配合墨黑底、旧绢白文字和宋体标题。使用内置 imagegen 分别生成；完整最终提示词见 [ui-wukong-prompts.json](ui-wukong-prompts.json)。原稿直接保存在项目中，未裁切、缩小或压缩，v1 青玉原稿及 [ui-prompts.json](ui-prompts.json) 保留。

| 素材 | 尺寸 | 接入位置 | 原稿 |
| --- | --- | --- | --- |
| 古铜云雷四角 | 1254×1254 RGBA PNG | 普通弹窗四角，九宫格切片保持纹饰比例 | [panel-corners-v2.png](../public/art/ui/panel-corners-v2.png) |
| 菱形标题纹饰 | 2172×724 RGBA PNG | 普通弹窗标题下方的独立留白 | [title-ornament-v2.png](../public/art/ui/title-ornament-v2.png) |
| 古铜细线分隔 | 2172×724 RGBA PNG | 面板内已有分组标题下方 | [divider-v2.png](../public/art/ui/divider-v2.png) |

装饰采用真正透明通道。面板角纹以 `border-image-slice:44%` 显示，桌面 32 px、手机 26 px，避免随弹窗长宽拉伸。标题和分隔纹饰按原图 3:1 比例缩放并居中展示可见区域，文字仍由 HTML 绘制，长标题允许换行。

CSS 只引用三个 v2 固定包内路径，服务器白名单逐一开放当前及保留的 v1 文件；不新增任意路径或目录访问。所有装饰伪元素均 `pointer-events:none`，位于正文和按钮下层，不新增动画、游戏状态或素材查询接口。图片失败时装饰自然消失，原边框、文字、按钮和滚动继续可用。开始页、顶栏工具区、行动与日志同步墨黑古铜主题；左上角色状态区参考《鬼谷八荒》的信息布局，以原创纸色 CSS 渐变、古铜双细线和红/绿/蓝/金厚资源横条呈现，条内数值仍由 HTML 显示，圆形头像框复用现有男性立绘，以 `cover` 和顶部焦点呈现头部至胸腹的半身构图，桌面/手机/320 px 窄屏及低横屏直径为 96/72/64 px。3:4 原始素材保留，建档预览沿用原卡片展示，角色属性页继续完整显示 3:4 立绘；圆形框仅用于左上 HUD。左上角色状态区不引用本组纹饰图片、不新增图片或素材接口；普通面板、顶栏、行动/日志和开始存档区不使用背景模糊，资源、时钟与解锁规则沿用已有实现。

解锁及地点解锁回执沿用已有独立视觉，排除这组纹饰。人物、导航图标、地图坐标和路网保持原规则。当前导航文字轻微覆盖圆底下缘，并以 0.6 px 深青描边保持可读。

纹饰验收记录见 [墨黑古铜 UI 验证](TEST_REPORT_WUKONG_UI_2026-10-01.md)。v1 接入证据保留在 [UI 美术接入验证](TEST_REPORT_UI_ART_2026-10-01.md)。本轮左上圆形头像框记录使用 [圆形头像 HUD 专项](TEST_REPORT_PLAYER_HUD_CIRCLE_2026-10-01.md)，旧纹饰与纸色视觉报告不作为本次验证。

视觉参考：[《黑神话：悟空》界面截图集合](https://interfaceingame.com/games/black-myth-wukong/)、[PlayStation 官方素材](https://www.playstation.com/en-tw/games/black-myth-wukong/)。这些是设计参考，不是素材来源；项目中只使用独立生成的纹饰。
