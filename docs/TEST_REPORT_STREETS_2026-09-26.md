## 修改范围

- 按用户追加的“道路太过横平竖直，参考现实道路”调整地图表现：统一投影为斜向街道、缓弯、随河岸转折的道路与不规则街区。
- 老城院落、沿街店铺、住宅组团、商业楼群、校园、物流院、湖岸绿地和山麓村落分区绘制，补充路缘、人行道、行道树、停车位、路口斑马线及桥栏。
- `map-geometry.js` 为道路、建筑、地标、发现动画、骑手和路线提供同一制图投影；`map-art.js` 负责只构建一次的静态矢量底图。旧地点 ID、规则坐标、路径、里程、资源消耗与存档保持不变。
- 地图比例尺明确为骑手附近的局部近似值，随位置和缩放更新。投影图上的直线测量不能替代行动面板的实际路程。
- 应用仍为 1.19.0，schema 仍为 v22，没有发布新版本。

参考材料：[NACTO 街道设计指南](https://nacto.org/publication/urban-street-design-guide/)、[人行道设计](https://nacto.org/publication/urban-street-design-guide/street-design-elements/sidewalks/sidewalk-design/)和[路口过街设计](https://nacto.org/publication/urban-street-design-guide/intersection-design-elements/crosswalks-and-crossings/)。只借鉴街道空间组织，图形由本地 SVG 原创生成；没有导入真实城市地图、瓦片或道路数据。
