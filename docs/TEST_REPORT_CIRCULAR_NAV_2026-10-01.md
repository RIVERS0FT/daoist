# 圆形导航界面验证

日期：2026-10-01。应用 1.22.0，存档 v25。本轮为本机导航修改与专项验证，未提交、推送或部署。

## 实现范围

- 参考《鬼谷八荒》地图界面物件入口，使用独立深青圆形底座、细暖金边、既有手绘图标和下方标签。桌面圆底 48 px / 图标 32 px，手机与紧凑横屏圆底 44 px / 图标 28 px。未新增或替换素材文件。
- 当前面板、悬停及键盘聚焦强调边框；关闭或 Escape 后复原。`syncNavigation()` 只读真实 dialog 状态，在导航重建和弹窗打开/关闭时同步 DOM 与 ARIA，不参与帧轮询或修改游戏。
- 保留功能开放、强制事件、独立暂停原因与单一持续推进规则。手机内部横向滚动，导航命中至少 44 px。桌面为日志留空，短横屏将区域信息、行动条和日志分列，导航固定在下方。

## 后续文字叠放调整

文字改为轻微覆盖圆形底座下缘，采用 0.6 px 深青细描边，填色在描边之后绘制。桌面标签上边距 −12 px、手机和短横屏 −10 px，保持原按钮尺寸；文字使用独立层级置于图标上方。

真实 8787 四视口均通过。文字 Range 与圆底的实测垂直重叠为桌面 5 px、其余三视口 6 px，原标签仍完整可读。四视口十入口共 40 次点击重合的文字区域，命中标签并进入原面板；高亮、关闭、Escape、悬停、内部滚动、区域入口与暂停 JSON 检查均通过。页面异常、请求失败和 HTTP 错误均为零。独立存档、报告和截图在 `artifacts/nav-label-overlay/`。

这次样式调整的前两次 idle/panel 采集在 Chromium trace 导出阶段超时，未记录为通过。隔离诊断中 69.8 MB、325,930 个事件分 2,157 块导出，完整交付耗时 15.437 秒，接近原 15 秒截止；与旧成功采集的事件/帧密度差约 0.2%，不能据此归因文字描边。只将采样停止后的 CDP 导出等待改为 60 秒，保留超时异常，未改预算、场景或采样口径。诊断在 `artifacts/trace-export-diagnostic/`；用户随后要求绘制并接入新 UI 纹饰，最终叠放与纹饰的专项帧结果统一见 [UI 美术接入验证](TEST_REPORT_UI_ART_2026-10-01.md)。
