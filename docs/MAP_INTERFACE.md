# 地图主界面 v0.8

启动时先展示开始页。新建或选择存档后进入地图；保留 NPC 分支、多结局与 AI 协议，车辆规则和存档详见 v0.5 设计。

## 布局

- 整屏城市地图是默认主页，不再按长页面堆叠全部玩法。
- 顶部状态栏始终可见，第一识别信息为当前角色名称，不重复展示游戏标题；同时显示日期、时间、时段、天气、境界、金钱、灵气、精力、健康、压力、电量。点击境界查看详细状态；电量显示当前值 / 实际容量；设置/奇遇仅展示已固定的剧情模式。
- 左下角固定导航为地图、跑单、修炼、关系、奇遇、更多。更多包含生活、状态、命运分岔、帮助、设置和存档 / 返回开始页。不得改成仅桌面可见的导航。
- 右下角固定日志面板是行为与事件日志的唯一集中展示入口，直接读取现有 `game.log`；普通功能面板不再重复展示“最近见闻”，更多菜单不再提供单独见闻页。打开右侧功能面板时日志压缩为单条摘要，避免遮挡主要操作。
- 功能在右侧非模态面板中打开；手机端面板适应可用宽度，正文独立滚动，顶部状态和左下导航不能被覆盖。关闭按钮和 Escape 返回地图；键盘焦点回到触发按钮或地图导航。
- 城市名称与地图缩放/定位控制作为透明浮层覆盖在地图之上，地图画布继续延伸到这些控件下方；不得用实色顶栏切掉或遮住对应地图区域。按钮自身可保留半透明底、边框和轻微模糊以保证可读性。

## 简洁界面与帮助

- 主界面和普通功能面板只常驻当前状态、可执行动作、即时成本/收益、必要条件与恢复入口。不要反复展示玩法原理、自动保存机制、地图不会耗时等长期说明。
- 长期玩法解释统一进入“帮助”面板；开始页提供折叠式帮助，不展开时不占据主要视觉层级。帮助是查看操作，不推进游戏时间。
- 不能把会影响当前决定的信息移入帮助：资源不足原因、突破门槛、AI 授权与隐私提示、存档失败/冲突、待处理剧情、不可逆结局确认等仍须就地显示。
- 新建存档要求输入角色名称。游戏内顶部显示角色名称；旧存档继续使用既有槽名称作为角色名称，不改写存档结构。
- “关系”面板只展示 `relationships[npcId].met === true` 的人物。未相遇人物不生成卡片、姓名、职业、故事提示或“尚未相遇”占位；首次相遇仍由原剧情规则决定，查看关系或地图地点不能解锁 NPC。

## 地图入口

青岚市是虚构城市。地图采用随包提供的 SVG 街区、河流、道路和建筑，不请求地图瓦片、不申请定位、不引入地图服务密钥。支持鼠标拖动、触屏滚动、方向键平移、缩放、定位玩家、定位当前配送终点及常驻地点列表。

10 个常驻功能地标元数据位于 `src/game/cityMap.ts`。地点仅打开现有功能，不立即执行行动，不消耗或奖励资源，不传送角色、不免费解锁 NPC、不跳过路线条件。首次相遇仍由原剧情决定。

2400×1600 的地图拥有扩展的老城、学城、新城、港区、园区、南站和山麓道路。`deliveryLocations.ts` 定义 24 个商家取餐点与 40 个顾客送达点，各有独立坐标和稳定 ID。只有当前订单显示两个独立的“取 / 送”图钉及“玩家 → 取餐 → 送达”示意线，完成或取消后立即移除。配送点不出现在常驻地图或地点目录，功能地标仍保留。点击任务点打开当前配送面板，不立即移动。

玩家位置以独立标记及“当前位置”名称体现。新存档和缺少位置的旧存档从驿站开始，成功骑行或推车送达后更新到对应顾客点并自动保存；未主动平移暂停跟随时，镜头跟随；送达后保留玩家标记，不保留订单图钉。接单、取消、失败、浏览地图不会移动角色。不同槽的位置独立，刷新或换回存档从上次位置显示。

连线仅为方向示意，不代表最短路、连续移动或 GPS。配送距离、时间与收益仍按订单及车辆规则结算；其他生活/社交行动不新增出行模拟。定位玩家和定位终点只平移镜头，无订单时终点定位禁用。未知未来位置结构保护原档，不静默覆盖。

## 待处理故事与恢复

人工事件、自由奇遇、AI 请求和结局在触发或恢复存档时自动打开相应面板。玩家仍可收起面板浏览地图；地图上的“继续处理”和其他面板中的待处理提示提供恢复入口。

导航不会执行游戏 action，也不会取消或重发模型请求。只有 store 的返回开始页、切档、服务设置修改和回退操作会处理请求。所有实际行动仍经 store 检查 scene/pending/event/gameOver/loadBlocked，不能用地图绕过。

存档错误必须在全局显示，而不是只在奇遇面板中才能看到。新建独立存档不覆盖已有进度；只有主动放弃未保存的内存改动需要确认。既有人工剧情、经典零 AI 请求、生成场景保存和离线完成、多结局与旧档迁移继续完整可用。

## 统一缩放与手势（v0.8）

替换原生 scrollLeft/scrollTop 相机为 `screen = world * scale + translation`。鼠标左键、触笔和单指平移；双指以中点/距离同时缩放与平移，松开一指后从当前相机继续，取消/失焦后不得粘住。鼠标移过 6px、触屏移过 10px 认定为拖动，手势不得误触地标/接单；键盘按钮正常工作。

滚轮默认围绕光标缩放。视角菜单提供滚轮平移选项供触控板使用，ctrlKey 捏合仍缩放。不做设备猜测，不接管地图外部滚动或全局浏览器缩放。缩放下限由可用视口决定（全图可容纳 320px），最高 2×，缩小后次要地标文字收起，玩家和当前任务优先；图标采用反向缩放保持屏幕点击尺寸。无地图旋转和惯性。

定位玩家恢复跟随；手动拖动、滚轮、整图/整单查看暂停跟随。读取存档初始定位玩家。视角菜单包含全图、整单路线、四向按钮和滚轮偏好，方向键/+/-/Home 均可操作。整单定位扣除桌面侧栏宽度并留标记边距。镜头不写存档，不消耗种子/时间/资源。

回归增加纯缩放锚点与边界测试、拖动图钉不触发点击、双指退单指连续性、取消清理、真实 Chromium 触摸注入、面板滚动隔离及 WebKit 移动视口覆盖。自动化 WebKit 不等于真机 Safari 验证。

全图低缩放下，相距不足 64 个屏幕像素的功能地标聚合成带数量的标记；点击仅放大该组位置，不执行行动。普通缩放恢复独立地标，玩家和配送点不参与聚合，地点目录始终提供全部功能。
