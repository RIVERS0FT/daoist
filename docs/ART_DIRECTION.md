## 统一视觉方向

玩家仅允许男性角色。两款玩家立绘为 1086×1448 的 RGB 3:4 半身像，墨青配送外套、古铜细条、无标志头盔与深青灰背景，使用独立成年男性脸型，不借用 NPC 身份。通过内置 `image_gen` 分别生成，最终提示词和尺寸记录见 [player-appearance-prompts.json](player-appearance-prompts.json)。形象只决定视觉展示，不能改变玩家属性、关系、剧情或地图坐标。

左上角色 HUD 参考用户提供的《鬼谷八荒》截图的信息布局，使用原创旧绢纸色渐变、古铜双细线、墨色古风姓名与紧凑境界分隔。左上人物使用圆形头像框，复用男性原图，以 `cover` 与顶部焦点呈现头部至胸腹的半身构图，圆框直径为桌面 96 px、手机 72 px、320 px 窄屏与低高度横屏 64 px。3:4 原始素材保留，建档预览沿用原卡片展示，角色属性页继续显示完整 3:4 立绘；圆形框仅用于左上 HUD，不额外放大或变换原图；右侧纵向排列厚横条，红色对应气血、绿色对应体力、蓝色对应灵力、金色对应电量，当前值与上限用浅色数字居中置于条内。桌面条高 18 px、手机 16 px、窄屏与低高度横屏 14 px，资源名称和数字保持可读。面板材质与边线均由静态 CSS 绘制，不使用参考游戏原始素材、不新增装饰图片或模糊；时间、货币和返回操作保留在独立工具区，灵力继续遵守原有修行开放条件。

采用原创都市修仙 RPG 的半写实数字绘画，保留细腻但克制的绘画笔触、自然成年人体比例、清楚的面部和现代日常服饰。画面使用低饱和青绿、深青灰与适量暖金，柔和侧光，不用大片强光或巨大法术效果遮住人物。衣服和一至两件小道具表达职业，不依赖文字、品牌或机构徽记。

主视觉体现现代街巷、骑手的生活与安静的修行气氛，构图应留出页面标题和操作区的空间。展示用街景是插画背景，不作为地图道路或真实导航示意，不出现主线真相或后期人物身份。修行元素保持含蓄，不将配送工具、车辆或普通衣服画成华丽战甲。

人物立绘统一为 3:4 竖幅、单人腰部以上半身像，完整保留头顶和双肩，平视略微侧身，手部自然，周边留少量裁切余量。使用简洁深青灰渐变背景，不画具体地图地点，不添加其他人物。人物应保持独立的脸型、年龄、服饰与职业特征，不使用同脸模板、未成年外观、幼态比例或真人仿貌。

## 人物连续性与禁透边界

### 周野 · `zhou`

25 岁成年男性，职业为骑手。脸型略方、下颌利落、浓眉、深棕瞳，稍乱的黑色短发、日晒小麦肤色，精瘦结实，眼神明亮直接，带坦率笑意。固定识别点为暖赭色配送外套、深灰内搭、低调反光细条与无标志头盔。头盔夹在臂弯，另一只手自然握旧手机，不添加平台商标或危险抢行场景。

本批是早期普通骑手版本，不出现灵力、法阵、黑签、蚀灯纹、组织徽记或提前敌对的神情。修仙者身份仅在人物线第六段结算后可知，蚀灯会身份仅在第七段结算后可知，敌对外观仅在第九段决裂后适用。后续变体保留同一张脸、短发、赭色外套和头盔，按已经结算的 `bonds.zhou.stage` 选择，不以好感或总章节数代替人物阶段，不让早期素材提前透露后续身份。

### 林晚 · `lin`

24 岁成年女性，职业为行政秘书，负责日程、会议与社区项目联络协调。偏窄鹅蛋脸、平直眉、眼尾略垂、深棕瞳，黑发低髻与少量耳边碎发，自然浅暖肤色，肩背端正。神情专注、克制体贴，忙碌后略有倦意。固定服饰为米白日常西装外套与雾蓝衬衫，日程本抱在腰前，另一只手拿黑色签字笔。

回春医馆只是常约地点，不改变行政职业。素材不添加白大褂、听诊器、医疗身份、医疗承诺或机构徽记，不把初识画成已恋爱，也不提前呈现尚未完成剧情中的私人往事。

## 行囊物品

行囊采用同一半写实手绘方向，以自然材料与清楚轮廓表现物品：12 个药种分别使用不同瓶器形状与主要颜色，清心散使用散剂纸包；64 种药材共享 14 类外形，36 本功法按可信来源共享 6 类卷册，另有 5 件独立道具与装备，共 37 张原稿覆盖 213 个当前物品 ID。古铜、青玉、陶瓷、木、纸、布与草木各保留自然质感，不统一染成单一青色。

每张独立生成，全部实际原稿为 1254×1254 RGBA 的真实 alpha 透明 PNG，尺寸、透明通道和完整性已通过本机素材验证；主体居中约占 70%，在 64 px 下仍可辨认，所有瓶塞、根须、枝叶与卷轴端点完整。素材不绘文字、品阶、数量、背景、UI 框或光环；原稿保存于 `public/art/items/`，不裁切、不另行缩小或压缩。内置生成提示词与逐物品 ID 映射见 [item-prompts.json](item-prompts.json)。

图片当前仅用于行囊，系统商店保留原字形。`G.Art.item(id)` 返回冻结的固定素材对象或 `null`，不读制作文档、不猜名称、不接收外部路径；名称、数量、真实品阶和按钮仍由 HTML 呈现。桌面 64 px、窄屏 56 px 等比展示，图片不响应指针，失败后回退字形。接入、浏览器与专项性能证据见 [行囊美术验证报告](TEST_REPORT_INVENTORY_ART_2026-10-01.md)，完整发布验证见 [1.22.0 发布验证](TEST_REPORT_RELEASE_1.22.0.md)。

## 生成、命名与验收

后续人物素材每次独立生成一个角色的一张图，不先生成多人物拼版再裁成不同人物。沿用同一视觉方向，并明确角色 ID、实际成年年龄、职业、固定外貌与当前披露阶段；需要变体时使用已验收原图作为连续性参考。

素材命名采用 `角色ID-用途-vN.png` 或 `night-courier-用途-vN.png`，例如 `zhou-rider-v2.png`、`lin-office-v2.png`。`vN` 表示素材修订号，不等同于应用版本或存档 schema。默认新增版本文件，保留已有素材，不静默覆盖；未验收结果不得替换页面正在使用的版本。

验收应核对角色身份、实际年龄、职业与服饰，检查脸、手部、裁切余量、背景和与其他素材的风格一致性；确认没有文字、水印、品牌、机构标志、额外人物或剧情剧透。通过验收后再更新本文件状态；页面接入及浏览器验证单独记录，不以“已生成”代替“已接入”。

## 本地发布与工程边界

可发布的图片存放于 `public/art/`，以相对资源路径随静态包发布，运行时不依赖图像生成服务、外部图床或第三方链接。页面接入按实际用途设置替代文本、裁切与显示尺寸，不能遮挡既有操作区域。

UI 纹饰保存在 `public/art/ui/`，只作为固定 CSS 装饰展示，不绘制文字、余额、奖励或时间。普通面板参考《黑神话：悟空》的金石与留白气氛，独立绘制古铜云雷纹饰；不使用参考游戏的角色、徽记或原始素材。普通面板、开始页、顶栏工具区、行动和日志使用墨黑、旧绢白及古铜色，朱砂用于提示；左上角色状态区使用独立纸色方案，圆形导航和现有都市插画继续保留青绿暖金方向。采用真透明原稿、等比展示和固定角纹切片，装饰不响应指针、不增加循环动画；长标题、正文滚动和关闭操作优先。

`G.Art` 只返回固定包内路径，不接受 AI 文本或任意路径。人物原稿保留完整 3:4 构图，NPC 展示和角色属性页保留完整比例，建档预览沿用原卡片裁切；左上 HUD 单独使用圆形框与顶部焦点半身裁切，主视觉按完整比例展示；图片声明尺寸并异步解码，人物及功能图标延迟加载。资源失败监听隐藏损坏图片或插画容器，原有人物姓氏头像、名称、标签及按钮继续可用。使用生成原稿，未另行缩小或压缩。

美术只改变视觉呈现，不重排地点 ID，不移动地图坐标，不修改 `ROAD_NODES/ROAD_EDGES`，不改变区域边界、寻路、通行或配送规则。图片和动画不写玩家位置、资产、奖励、境界或游戏分钟，不替代 `G.perform` 的指令校验与 `G.advance` 的持续推进；人物展示仍遵守结识和分阶段披露规则。
