# 游戏美术界面接入验证

日期：2026-10-01。应用 1.22.0，存档 v25。本轮本机修改与专项验证，未提交、推送或部署。

## 实现范围

- 开始页展示都市骑手主视觉与配送箱莲花品牌图标，页面 favicon 使用同一应用图标。
- 十个渐进开放的功能导航、区域入口、订单标题、对应动作卡片接入手绘图标；手机导航内部横向滚动，按钮命中至少 44 px。
- 羁绊卡片和事件只为已结识林晚、已结识且个人线整数阶段 0–8 的周野展示对应 3:4 半身像；其他 19 位人物保留姓氏头像，敌对周野保留文字和头像。
- `G.Art` 为原生 IIFE 注册的只读白名单，不接受任意文件路径或 AI 文本，不写游戏资产、位置、奖励与时间。图片失败隐藏图像，原名称和操作继续可用。
- 图片声明尺寸并异步解码，人物与功能图标按需加载；位置文字未变化时不重建 PNG 节点。地图标记和实际路网保持原 SVG/真实坐标。
- 使用原始 16 张 PNG，未缩小或压缩；全部图片作为本地相对资源随多文件包发布。

## 验证边界

本轮按日常小改规则执行相关专项；未运行完整 Node / 浏览器套件、CI 或公网部署验收。AI 使用经典离线健康响应，不代表真实 AI 服务验收；未进行真实手机、慢网络或 CPU 降速测试。素材原稿较大，离线资源测量不能代表真实网络首屏下载时间。
