# 外卖修仙 — Game Design v0.2

## High concept

白天在现代城市送外卖维持生计，晚上在出租屋、天台和城市缝隙里修仙。游戏的主要压力来自有限时间：赚钱、吃饭、休息、修炼、调查异常、经营关系都消耗同一条不断向前的时间轴。

核心体验不是“几个互相独立的小游戏”，而是凡俗生活、人与人的关系和修仙世界不断互相污染：普通订单可能变成机缘，也可能让你认识一个以后会改变人生的人；通宵修炼会让第二天送餐更危险；收入决定房租和生活质量；是否愿意为别人花时间则决定友情、爱情、同道和最终归宿。

## Core loop

1. 查看日期、时间、天气、身体、经济、关系和修炼状态。
2. 选择一个会消耗游戏时间的行动。
3. 时间推进，资源与世界状态变化。
4. 根据行动上下文、时间、天气、人物关系和历史选择抽取事件。
5. 玩家处理事件，承担即时和长期后果。
6. 白天配送获得收入并接触城市人物；夜间修炼获得灵气，也更容易遇到异常。
7. 已认识的 NPC 可以主动联系，社交同样消耗时间，因此与赚钱、修炼形成真实取舍。
8. 第 30 天后玩家可以继续生活，也可以从已经成立的命运分支中主动选择结局。

## Time rules

- 一天 1440 游戏分钟。
- 时间只由玩家行动推进，不跟随现实时间。
- 默认阶段：06:00–09:00 早晨；09:00–11:00 平峰；11:00–14:00 午高峰；14:00–17:00 午后；17:00–20:00 晚高峰；20:00–24:00 夜晚；00:00–06:00 深夜。
- 夜晚和深夜提供更高修炼收益，也更容易触发异常事件。
- 跨日更新天气、生活压力与房租检查。
- 主动联系 NPC 默认消耗 45 分钟；剧情选择还可以继续追加时间成本。

## Player resources

现实资源包括金钱、精力、健康、压力、骑手信誉与电动车电量。修仙资源包括灵气、悟性、因果、阴气与境界。当前境界为凡人 → 炼气一层至九层。

## Delivery

接单消耗少量时间，生成商家、客户、距离、基础报酬与预计配送时间。完成订单会根据时间段、天气和随机波动消耗时间、电量、精力并获得收入和信誉。午高峰与晚高峰报酬更高，但随机风险也更高。配送是事件系统、超自然内容和 NPC 相遇的主要入口之一。

## Cultivation

吐纳可以随时进行，但夜晚效率更高。深夜修炼收益最高，同时会消耗更多精力并提升异常事件概率。突破固定消耗较长时间并具有失败风险。悟性、健康和压力影响稳定性。

## NPC relationship system

当前核心 NPC：

- 林小满：东城医院夜班护士。可发展为恋人、挚友或逐渐疏远。
- 周野：同站骑手。重点是骑手友情、互助和共享秘密。
- 苏青禾：旧书店店员。重点是修仙同道、知识交换与共同冒险。
- 王叔：老王牛肉面老板。重点是人情、照顾和“没有血缘的家”。
- 许遥：自由摄影记者。重点是真相、信任、公开与保守秘密的冲突。

每个 NPC 使用四个关系维度：

- `affinity` 好感：相处是否舒服、愿不愿意接近。
- `trust` 信任：是否愿意把危险和秘密交给对方。
- `bond` 羁绊：共同经历是否足够深。
- `romance` 情感倾向：只在部分关系中有意义，不代表路线必然进入恋爱。

此外每人拥有 `route`，可进入朋友、挚友、恋人、同道、伙伴、家人式关系、疏远等状态。重要剧情选择会锁定或关闭路线。游戏不会把“最高好感 = 恋爱”作为默认逻辑。

## Story event system

事件是主要内容载体。每个事件包含 id、标题、分类、描述、行动上下文、基础权重、出现条件、NPC、多个选择、即时效果、关系变化与事件旗标。事件类别包括配送、商家、顾客、交通、天气、生活、修炼、灵异、机缘、NPC 和连续剧情。

事件选择可以产生：

- 数值变化；
- 时间消耗；
- 世界旗标；
- NPC 好感 / 信任 / 羁绊 / 情感变化；
- NPC 路线锁定；
- 后续剧情条件；
- 结局条件。

连续剧情通过 flags 和 relationship state 推进。同一事件近期不会明显重复；已完成的主线阶段应通过条件自然退出事件池。

## Endings

第 30 天后开放“命运分岔”。玩家不是自动进入最高分结局，而是从当前已经满足条件的结局中主动选择，也可以继续游戏等待更多可能性。

当前结局方向包括：

- 情感：与林小满一起等待天亮。
- 友情：与周野成为真正能互相托底的同行。
- 修仙：与苏青禾离城寻找更远的修行线索。
- 羁绊：在王叔的小店形成没有血缘的家。
- 城市：与许遥把部分超自然真相带到白天。
- 守护：隐藏真相，成为城市夜晚的无名守护者。
- 独行：牺牲关系，只追求境界。
- 暗线：逐渐走进鬼市与城市背面的世界。
- 人间：继续普通生活，既不逃离凡俗也不放弃修行。

多结局不做价值排名；每个结局代表玩家长期选择形成的一种生活。

## Optional AI narrative enhancement

AI 可以接入，但只增强 NPC 对白、反应和氛围文字。AI 不拥有游戏规则权：不能直接修改数值、关系、旗标、路线、突破结果或结局判定。

核心剧情始终有人工编写版本，未接入 AI、网络失败或服务超时时必须完整可玩。Web 客户端不得保存模型供应商密钥；如需接入在线模型，应通过独立的服务端 relay，并只发送当前虚构场景所需的最小上下文。

## Current scope

当前版本目标为一个关系驱动的完整纵切面：连续时间与跨日、天气、配送和经济压力、炼气成长、60+ 数据驱动事件、5 名核心 NPC、多条关系路线、多结局、v1→v2 存档迁移、IndexedDB 自动存档、可选 AI 叙事增强和 GitHub Pages 单机部署。

后续阶段可加入装备、药材、炼丹、更多 NPC、城市区域、战斗、筑基、轮回以及跨周目关系回响。
