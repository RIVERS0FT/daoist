# 外卖修仙 — Game Design v0.1

## High concept

白天在现代城市送外卖维持生计，晚上在出租屋、天台和城市缝隙里修仙。游戏的主要压力来自有限时间：赚钱、吃饭、休息、修炼、调查异常都消耗同一条不断向前的时间轴。

核心体验不是“两个互相独立的小游戏”，而是凡俗生活和修仙世界不断互相污染：普通订单可能变成机缘，通宵修炼会让第二天送餐更危险，收入又决定玩家能否承担房租、食物、车辆与未来修炼成本。

## Core loop

1. 查看当前日期、时间、天气、身体与经济状态。
2. 选择一个会消耗游戏时间的行动。
3. 时间推进，体力/压力/资源随行动变化。
4. 根据行动上下文、时间、天气、人物状态抽取随机事件。
5. 玩家处理事件并承担即时与长期后果。
6. 白天通过配送获得金钱与城市关系，夜间通过修炼获得灵气与境界。
7. 房租、疲劳、健康等长期压力持续逼迫玩家取舍。

## Time rules

- 一天 1440 游戏分钟。
- 时间只由玩家行动推进，不跟随现实时间。
- 默认阶段：06:00–09:00 早晨；09:00–11:00 平峰；11:00–14:00 午高峰；14:00–17:00 午后；17:00–20:00 晚高峰；20:00–24:00 夜晚；00:00–06:00 深夜。
- 夜晚和深夜提供更高修炼收益，也更容易触发异常事件。
- 跨日后更新天气、生活压力与房租检查。

## Player resources

现实资源包括金钱、精力、健康、压力、骑手信誉与电动车电量。修仙资源包括灵气、悟性、因果、阴气与境界。MVP 的境界为凡人 → 炼气一层至九层。

## Delivery

接单消耗少量时间，生成商家、客户、距离、基础报酬与预计配送时间。完成订单会根据时间段、天气和随机波动消耗时间、电量、精力并获得收入和信誉。午高峰与晚高峰报酬更高，但随机风险也更高。配送是事件系统最重要的入口之一。

## Cultivation

吐纳可以随时进行，但夜晚效率更高。深夜修炼收益最高，同时会消耗更多精力并提升异常事件概率。突破固定消耗较长时间并具有失败风险。悟性与当前健康会影响稳定性。

## Random event system

事件是主要内容载体。每个事件包含 id、标题、分类、描述、行动上下文、基础权重、出现条件、多个选择、即时效果与事件旗标。事件类别包括配送、商家、顾客、交通、天气、生活、修炼、灵异、机缘与连续剧情。同一事件不应在短时间内连续出现。连续剧情通过 `flags` 推进阶段。

## MVP scope

当前版本形成一个完整可玩的纵切面：连续游戏时间与跨日、天气、随机订单与高峰收益、钱/精力/健康/压力/信誉/电量、房租压力、吐纳与炼气突破、30+ 数据驱动随机事件与事件链、IndexedDB 自动存档、重新开局、GitHub Pages 单机部署。

后续阶段再加入装备、药材、炼丹、NPC 关系、更多事件链、城市区域、战斗、筑基及轮回。
