## 新增覆盖

职业专项核验九位女性的精确职业映射、学生／模特／秘书／主播均存在、全部12人的职业唯一以及年龄不变。对全部48段人物故事和全体事件的非文本规则字段与修改前指纹比较一致，确保奖励、消耗、耗时、物品、关系路径、人物关联和事件ID没有随文案改写改变。

每位女性均检查卡片配置、配送身份、半身像正负提示词、AI人设及JSON导出同源。经典和AI模式下逐一恢复九人四段旧待选，确认身份／文本从可信模板重建、非法奖励和关系覆盖被丢弃；每人有耗时选项时另验证途中读档、剩余时间、支付和一次性结算。旧已结算结果、日志及相伴关系原样保留。重复、空白或缺失的职业配置在资料加载时拒绝。

主播代理测试使用模拟上游，按许知夏ID重建20岁知识区主播资料，丢弃客户端提供的旧职业和未来话题；只传已完成的话题标题，保持未明确选择感情时不默认恋爱。
