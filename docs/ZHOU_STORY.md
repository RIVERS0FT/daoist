# 周野 · 同路与歧路

版本 1.19.0。25岁，职业：骑手。以下为完整编剧剧透，不是早期人物介绍。

关系顺序：路人 → 朋友 → 兄弟 → 仇人。阶段必须逐段结算，前四段沿用原好感条件，后六段以境界、累计配送和系统开放控制。旧版完成四段的朋友存档接到兄弟阶段，不重播、不直接成仇。

蚀灯会是本作虚构的邪恶修行组织，以掠夺普通人的愿力扩张力量。周野最初为家中债务接受它的资源，后来为变强主动提供路线，并非被操纵的无辜者；他对同行的真心与其主动伤害他人的选择同时成立。第九段三个回应均决裂，不设置玩家加入组织或一键洗白路线。

## 第1段：同一盏红灯

前置：前段完成；好感至少0。关系在本段结算后为路人。

周野把头盔挂在车把上，认出了上次帮过他的你。「我叫周野，跑外卖的，早高峰、午饭点、夜里都接，哪会儿有单就在哪会儿跑。」他把裂屏手机翻扣在桌上，先问你今天吃过饭没有。此刻你认识的，只是一个爱逞强也肯帮人的同行。

### 选择1：请他喝杯豆浆

你们各自讲了一单最难找的门牌。周野笑得直拍桌子，却把你的热豆浆挪到了背风处。没有豪言，只有一顿没人催的饭。

效果：`{"money":-5,"affinity":7,"trust":3}`；耗时：0游戏分钟。

### 选择2：交换常跑路线

你们把午间会堵的巷口和晚归时能歇脚的店记在同一页。周野说：以后看见你的车停在路边，我总要问一句。

效果：`{"affinity":6,"trust":4,"rep":1}`；耗时：0游戏分钟。

### 选择3：问他伤好些没有

他嘴硬说只是擦伤，还是听你的把护膝重新系紧。「上次欠你的情，记着呢。」你让他先别把自己再摔一次。

效果：`{"affinity":5,"trust":4}`；耗时：0游戏分钟。

## 结算与兼容

第六段结算后才更新修仙者身份，第七段结算后才更新蚀灯会身份；第九段结算后关系为仇人，好感与信任归零。第十段为敌对余波，之后不开放友好拜访。新订单不再抽取敌对周野，旧票据仍可完成但不恢复关系。已获得丹方和旧历史保留；未获得的周野丹方在修为揭露后、尚未成仇时按原信任要求传授。角色路线不代替十二章主线，不增加战斗、瞬移、强制结局或自动经济收益。
