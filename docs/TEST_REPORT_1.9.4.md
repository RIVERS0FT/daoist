# 1.9.4 配送外卖币解锁门槛测试记录

日期：2026-09-20。基线：main / 1.9.3；本次应用版本 1.9.4，存档维持 v16。

## 范围与边界

- 真正新档的经典、AI 模式及首单三个选项；接单、途中、到达待选、读档及实际结算均不提前发币；首单结算才开启系统。
- 系统开启后的订单和额外事件奖励保持原额；开启前已经生成的订单保留原额，之后接取可正常获币，不补发首单。
- 经典与 AI 配送正币奖励、无事件直接交付、耗时选择及途中读档均检查门槛；负成本、非币效果和非配送事件保持原规则。
- 原有余额、已读或未读回执保留；重复选择、旧订单重接、确认解锁不重奖；房租破产优先；签到、委托数值不变。
- 1200px 和 320px 界面检查未开启订单只显示现金、首单结果无币、解锁后订单展示及到账、旧配送事件选项与结果不虚报币。

## 本地验证

`npm run check`、`npm test`（608/608，含新增 19 项）、`npm run build` 通过。

`python tests/browser-smoke.py` 的新增 6 组交互检查全部通过，另已通过人物／功能解锁和地点解锁等既有场景。全量运行在本地工具时限处被停止，没有出现断言失败；不将部分运行当作全量通过。已查看 320px 首单结果截图，配送栏只显示现金与口碑，按钮及卡片无横向溢出。
