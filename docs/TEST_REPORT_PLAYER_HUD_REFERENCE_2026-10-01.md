## 变更

用户确认参考《鬼谷八荒》的角色信息区布局。左上玩家状态区改为原创纸色底、古铜双细框与墨色姓名/境界；左侧保留当前存档的完整 3:4 男性半身立绘。右侧横向资源条按气血红、体力绿、灵力蓝、电量金区分，数值与上限置于条内。

桌面条高 18 px、手机 16 px、320 px 窄屏和低高度横屏 14 px。边框、分隔、渐变均由静态 CSS 绘制，没有引入纹理图片、模糊或动画；时间、倍率、货币和返回操作沿用独立工具区。地图仍按顶栏实际高度布局，短屏地图说明间距随可用空间收紧。

沿用两款男性形象、修行开放后显示灵力、真实资源与进度条 ARIA、普通帧 DOM 保留和四位百分比归一化规则，不改引擎、存储格式或游戏数值。参考的是布局与古风视觉语言，未将参考截图作为游戏资产。
