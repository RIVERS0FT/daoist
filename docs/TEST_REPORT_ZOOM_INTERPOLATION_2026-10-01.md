# 地图缩放插值专项验证

日期：2026-10-01。应用 1.22.0，存档 v25。本轮为本机实施与专项验证，未提交、推送或部署。

## 修改范围

- 滚轮、按钮、键盘与双击共用 180 ms 三次缓出插值，按真实 RAF 时间更新地图比例；Canvas 瓦片、路线和交互标记同步，图标保持屏幕尺寸。
- 使用 `L.Point` 表示容器像素锚点。同向输入累积目标，反向输入从当前显示比例重定向；拖动、双指起手、定位、全城、视图重置和容器 resize 终止旧插值及待执行滚轮防抖。
- 中间帧复用现有瓦片，结束后提交目标整数级别；标签避让延至移动结束，全市分区不因标记概览阈值额外重画底图。
- 原生双指缩放连续跟随手势；系统减少动态效果时立即显示目标比例。镜头操作不写玩家位置、资源或游戏时间。
- 设计、架构、项目记忆和待发布版本说明同步；固定 Leaflet 1.9.4 私有连续移动接口的依赖记录在架构中。
