## 帧性能专项

运行 `tests/browser-performance.py --root public --scenes idle,panel --output artifacts/performance-wukong-ui`，桌面与手机共 4 / 4 场景通过。默认帧预算 16.667 ms；200 ms 长任务自检观察到 204.444 ms 并正确捕获，不计入场景预算。此次专项使用本地资源拦截供给，真实 HTTP 由上面的独立浏览器专项另行验证。

| 视口 | 场景 | P95 ms | P99 ms | 最大 ms | 超预算比例 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1440×1000 | idle | 8.149 | 11.942 | 29.747 | 0.288% |

全部 21 个加载模块逐场景保留采样行；布局、样式、绘制、合成、主线程占用、栅格工作线程与 GPU 服务线程均有逐帧统计，完整表格见 `artifacts/performance-wukong-ui/report.md`，JSON、CPU profiles 和 Chromium trace 保存在同一目录。零采样只表示未采到，不代表模块没有开销；多线程工作可重叠，不能加总当作整帧时长。这是浏览器 RAF 回调入口间隔，不代表物理屏幕显示或精确 GPU 着色器耗时。
