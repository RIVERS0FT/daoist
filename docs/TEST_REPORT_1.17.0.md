默认人物介绍、画像及AI人设不泄露未来身份；按已完成阶段分别提供修仙者、组织成员及敌对上下文。完整剧本与提示词手册标明编剧剧透。没有新增自动战斗、瞬移、组织经营、加入邪恶组织或一键洗白路线，未生成图片。

## 主要边界覆盖

十段、三选项、两种模式均检查前置与真实结算，含停止、无效选择、重复提交、8/10/12分钟耗时、未读回执、房租优先及保存/恢复。关系以已结算进度更新，不因仅触发事件、查看面板或读档提前成为兄弟或仇人；当前非法阶段/路径、伪造固定模板身份、敌对友好拜访与外来奖励拒绝。

v20及以前合法周野四段进度迁移到新线已完成前缀，完成四段的旧朋友接到兄弟阶段，不自动揭露身份、成仇或补发奖励。旧待选使用当前可信文案、保留票据/资产；已结算回执和日志原样保留。专门覆盖旧版三分钟重逢途中快照，迁移后及再次读档仍保留剩余时间、原效果，不替换成即时完成或重复结算。其他人物、十二章主线、第十单随机地点解锁、路线、时钟、租金与原存档兼容回归保留。

默认画像及AI资料不含蚀灯会、邪恶组织或修仙者身份，阶段6/7/9分别开放对应知识；敌对画像使用冷淡戒备神情。服务端按可信NPC ID与清理后的关系构造阶段提示，拒绝客户端身份覆盖；关系数值仍为单机上下文，不是服务端防作弊。模拟代理验证未将未来整段剧本泄露到早期请求。
