# 全市地图、接缝与帧长验证 · 2026-09-27

## 本轮结果

- 上海全市背景采用同一份分区数据及统一细节阈值，移除原城区单独叠加的精细底图。相同缩放下，原城区与外围同时显示 OSM 已有建筑、小路及水系，日夜配色一致。
- 192 px 瓦片四周补绘 2 px，保持地图坐标不变；分区读取考虑文字和宽道路外延，避免相邻分区截断。修复比例尺在接近十进制边界时因浮点误差显示 `undefined`。
- 保留原城区数据库字节、110 个地点 ID 与坐标，新增 375 个真实道路可达的虚构地址，总计 485 个。不新增轮渡或虚构跨水域连接。v23 途中存档保留原路线，非法路段仍拒绝。
- 全市背景、路线和图标共用米制坐标；动态 SVG 使用未取整的投影边界，避免全市总览下小尺寸图层取整造成玩家坐标漂移。

数据来源、精度、许可及复现命令见 [MAP_DATA.md](MAP_DATA.md)。本轮未改变应用版本或存档 schema。

## 帧长与模块耗时

沿用整页真实 RAF、Chrome trace 和 V8 采样，不用地图函数的同步耗时代替整帧。报告列出全部 19 个脚本模块，以及布局、绘制、合成、栅格、GPU 服务线程分类。零采样不表示零开销，各线程累计耗时不能直接相加当作帧长。

本机帧预算：P95 ≤ 33.5 ms，最大值 ≤ 150 ms，超过目标 16.667 ms 加 0.5 ms 容差的帧占比 ≤ 10%。报告包含 P99 与每模块逐帧摘要，并通过地图外注入 200 ms 长任务确认检测生效。

## 验证边界

按用户要求，本轮只运行地图、路网、帧长和构建相关专项；未运行完整 Node / 浏览器功能套件，完整测试留到推送前。PR 与部署工作流已增加接缝及全模块帧长检查。

未提交、推送或部署，未触发远端 CI、RIVERSOFT 发布或公网内容校验。实际手机、其他浏览器及用户设备的物理显示帧率未验收。此前地图/帧长报告属于扩图前阶段，不能代替本报告的全市验证。
