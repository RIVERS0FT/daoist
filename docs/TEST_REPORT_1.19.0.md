## 新规则覆盖

`tests/five-sects.test.mjs` 新增 160 项测试，覆盖：

- 36 种功法的唯一 ID、渠道、门槛、扣费、重复兑换；系统与宗门来源不能互相绕过。
- 五宗各自的入宗、执事、晋升、贡献支出与进行中存档；异宗典籍、贡献、任务不能串用。
- 单一宗门身份、离宗保留历史和功法、全局转宗冷却、取消入宗或考核不能提前获益。
- 原有三本听雨观典籍的 ID、成本与效果保持兼容；v21 迁移不清空原宗门、不重发奖励。
- 现代存档缺失状态、双重成员、跳过剧情、错误选项、非法功法、伪造在途关联均拒绝恢复。
- 气血 / 体力 / 灵力上限、步行速度、真实移动体力、吐纳 / 入定 / 淬体收益、突破率、成丹率、额外产出和炼药熟练度加成。
- 功法叠加上限及突破 95%、成丹 98%、额外产出 65% 的最终概率上限。
- 20 段宗门剧情的全部 60 个选项，以及 3 场五宗议事的全部 9 个选项。
- 经典 / AI 存档的固定宗门剧情恢复，AI 不可替换引荐或外交结果。
- 10 组宗际关系的确定性计算、先后门槛、散修议事与合作选项条件。
- 房租与宗门完成同刻时破产优先，存在配送中的订单时不能用宗门剧情覆盖它。

截图保存在本机临时 artifacts 目录，未作为游戏源码提交。浏览器 AI 测试使用受控模拟接口，不宣称完成真实外部模型联调。

## 范围说明

五宗强弱是当前世界观与界面设定，包括综合序位、最高境界及攻坚 / 防御 / 补给 / 洞察四项。没有新增战斗引擎，不能把这些设定解读为已经实现的战斗伤害或宗门战争模拟。

宗门沿用现有服务地点作为驻点，110 个地点、旧坐标与道路未调整；丹方仍遵循既有剧情 / 羁绊 / 商店三种渠道。新增宗门剧情不改写 21 位 NPC 的年龄、职业或个人主线。
